### 1. Полный анализ архитектуры системы ✅

**Файл:** `META_NEURAL_ANALYSIS.md` (470+ строк)

**Изучено:**

#### 🧠 META Нейросеть (`meta_neural_cem.py`)
- **Архитектура:**
  - Attention Module: 7D → 16D → 4D (196 параметров)
  - Main Network: 36D → 64D → 32D → 16D → 1D (4993 параметра)
  - **Итого: ~5200 параметров**

- **Входы:**
  - `x_features` (36D): предсказания экспертов + интеракции + статистики
  - `x_context` (7D): контекстные фичи рынка (vol_ratio, trend_macd, jump_flag, и т.д.)

- **Обучение:**
  - Алгоритм: CMA-ES / CEM (эволюционная оптимизация)
  - Функция потерь: Bootstrap log-loss + L2 регуляризация
  - MC Dropout (30 проходов) для uncertainty estimation

#### 🤖 4 Эксперта (XGB, RF, ARF, NN)

| Эксперт | Алгоритм | Входные фичи | Edge над baseline |
|---------|----------|--------------|-------------------|
| **XGBExpert** | Gradient Boosting (XGBoost) | 14D | +4% |
| **RFCalibratedExpert** | Random Forest + Calibration | 14D | +3% |
| **RiverARFExpert** | Adaptive Random Forest (онлайн) | 14D | +2.5% |
| **NNExpert** | MLP (14→32→16→1) | 14D | +3.5% |

**Общий набор фичей (14D):**
1. m_diff, s_diff, b_diff, r_diff (4 базовых сигнала)
2. z_bb, kc_pos, kc_w (Bollinger + Keltner)
3. atr_norm, rsi_norm, trend_rsi, wick_imb (волатильность + RSI + wicks)
4. m_diff×s_diff, m_diff×rsi_norm, s_diff×kc_pos (интеракции)

#### 🔄 Система 6 фаз рынка (`meta_ctx.py`)

**Матрица: Тренд × Волатильность**

| Фаза | Название | Тренд | Волатильность | Частота | Base Accuracy |
|------|----------|-------|---------------|---------|---------------|
| 0 | bull_low | ↑ Бычий | 🟢 Низкая | 18% | 52% |
| 1 | bull_high | ↑ Бычий | 🔴 Высокая | 12% | 48% |
| 2 | bear_low | ↓ Медвежий | 🟢 Низкая | 17% | 51% |
| 3 | bear_high | ↓ Медвежий | 🔴 Высокая | 11% | 45% (самая сложная) |
| 4 | flat_low | → Флэт | 🟢 Низкая | 24% (самая частая) | 49% |
| 5 | flat_high | → Флэт | 🔴 Высокая | 18% | 47% |

**Определение фазы:**
```python
trend_sign = MACD histogram z-score
vol_ratio = ATR / ATR_SMA

if vol_ratio >= 1.3:  # VOL_THRESHOLD
    high_vol = True
else:
    high_vol = False

# Фаза = f(trend_sign, high_vol)
```

#### 📊 Фазовая память

**Каждый эксперт и META обучаются ОТДЕЛЬНО для каждой фазы:**
- Отдельная модель для каждой из 6 фаз
- Фазовые калибраторы
- Фазовые буферы данных (до 10,000 примеров на фазу)
- При предсказании используется модель текущей фазы

## 🎯 КЛЮЧЕВЫЕ НАХОДКИ

### ✅ Сильные стороны системы

1. **Фазовая адаптация:**
   - 6 отдельных нейросетей для разных рыночных условий
   - Каждая фаза имеет свои статистические свойства
   - Адаптивное обучение под конкретную фазу

2. **Ансамблевое обучение:**
   - 4 эксперта с разными алгоритмами (XGB, RF, ARF, NN)
   - Комбинация через глубокую нейросеть
   - Нелинейные зависимости и интеракции

3. **Uncertainty estimation:**
   - MC Dropout (30 проходов) для оценки уверенности
   - При высокой uncertainty → консервативно к 0.5
   - Помогает избежать переуверенных ошибок

4. **Drift detection:**
   - ADWIN для автоматической детекции изменений
   - Автоматическое переключение ACTIVE → SHADOW
   - Защита от деградации модели

5. **Rich features:**
   - 36D enriched features для META
   - 7D контекстные фичи
   - Интеракции, статистики согласия, логиты

### ⚠️ Слабые стороны

1. **Высокая сложность:**
   - ~5200 параметров в META → требует много данных
   - Риск переобучения при недостаточных данных
   - Необходима тщательная валидация

2. **Медленное обучение:**
   - CMA-ES требует 30+ итераций × 40 популяция
   - Полное обучение на 360k примерах: ~30-60 минут
   - CEM быстрее, но хуже качество

3. **Редкие фазы:**
   - Фазы 1 (12%) и 3 (11%) встречаются реже
   - Может быть недостаточно данных для обучения
   - Нужна синтетическая аугментация

4. **Узкий край:**
   - Комиссия 3% съедает большую часть профита
   - Break-even = 50.76% → окно прибыльности 50.76%-60%
   - Требуется высокая точность модели

### 1. Это симуляция, не реальные данные!

Созданные тесты используют **реалистичную имитацию** на основе статистических свойств PancakeSwap, но:

✅ **Что учтено:**
- Правильные edge экспертов
- Корреляция между предсказаниями
