## 🔍 Детальный анализ архитектуры

### META Нейросеть

**Входы:**
- `x_features` (36D): предсказания экспертов + интеракции + статистики согласия
- `x_context` (7D): контекстные фичи рынка (vol_ratio, trend_macd, jump_flag, и т.д.)

**Архитектура:**
```
Attention Module: 7D → 16D → 4D (196 параметров)
Main Network:     36D → 64D → 32D → 16D → 1D (4993 параметра)
Dropout:          [0.20, 0.20, 0.15]
MC Dropout:       30 проходов для uncertainty estimation
```

**Обучение:**
- Алгоритм: CEM (Cross-Entropy Method) или CMA-ES
- Функция потерь: Bootstrap log-loss + L2 регуляризация (λ=0.0001)
- Фазовое обучение: отдельная модель для каждой из 6 фаз

### 4 Эксперта

| Эксперт | Алгоритм | Фичи | Edge над baseline |
|---------|----------|------|-------------------|
| **XGB** | Gradient Boosting | 14D | +4% |
| **RF** | Random Forest + Calibration | 14D | +3% |
| **ARF** | Adaptive Random Forest (онлайн) | 14D | +2.5% |
| **NN** | MLP (14→32→16→1) | 14D | +3.5% |

**Общий набор фичей (14D):**
1. m_diff (momentum difference)
2. s_diff (VWAP slope difference)
3. b_diff (Keltner breakout difference)
4. r_diff (Bollinger reversion difference)
5. z_bb (Bollinger z-score)
6. kc_pos (Keltner position)
7. kc_w (Keltner width)
8. atr_norm (normalized ATR)
9. rsi_norm (normalized RSI)
10. trend_rsi (RSI slope)
11. wick_imb (wick imbalance)
12-14. Интеракции (m_diff × s_diff, m_diff × rsi_norm, s_diff × kc_pos)

### Система фаз (6 фаз)

**Определение фазы:**
```python
trend_sign = +1 (bull), -1 (bear), 0 (flat)
vol_ratio = ATR / ATR_SMA

if vol_ratio >= 1.3: high_vol = True
else: high_vol = False

# Матрица 3×2:
if trend_sign > 0:
    phase = 1 if high_vol else 0
elif trend_sign < 0:
    phase = 3 if high_vol else 2
else:
    phase = 5 if high_vol else 4
```

## 🧪 Что тестирует скрипт

### 1. Генерация реалистичных данных

Для каждой фазы генерируются примеры с:
- **Реалистичной базовой точностью** (45-52% в зависимости от фазы)
- **Правильным edge экспертов** (XGB +4%, RF +3%, и т.д.)
- **Корреляцией между экспертами** (0.55-0.75)
- **Фазовой uncertainty** (0.08-0.16 в зависимости от фазы)
- **Контекстными фичами**, соответствующими фазе

### 2. Обучение META

- Собирает train данные (80% от каждой фазы)
- Обучает 6 отдельных нейросетей (по одной на фазу)
- Использует CEM оптимизацию с bootstrap log-loss
- Валидирует через cross-validation

### 3. Тестирование на hold-out

- Тестирует на оставшихся 20% данных (не видел во время обучения)
- Рассчитывает accuracy, Brier score, log-loss
- Разбивает результаты по фазам
- Оценивает прибыльность

## ⚠️ Важные замечания

### 1. Это симуляция, не реальные данные

Скрипт генерирует **реалистичную имитацию** на основе статистических свойств PancakeSwap, но:
- ✅ Учитывает правильные edge экспертов
- ✅ Учитывает корреляцию между предсказаниями
- ✅ Учитывает сложность разных фаз
- ❌ Не учитывает все нюансы реального рынка
- ❌ Может быть слишком оптимистичной

**Реальная производительность на live данных может быть на 2-5% ниже!**

### 2. Требования к real data

Для обучения на реальных данных нужно:
- Минимум 50,000 раундов (лучше 100,000+)
- Данные за последние 3-6 месяцев
- Все 6 фаз должны быть представлены
- Качественные фичи (без NaN, правильная нормализация)

### 3. Риски переобучения

META имеет ~5200 параметров, поэтому:
- Нужно много данных (минимум 150 примеров на фазу для обучения)
- Обязательна валидация на hold-out данных
- Dropout (0.15-0.20) помогает, но не панацея
- L2 регуляризация критически важна

### 4. Paper trading обязателен!

Даже при хороших результатах тестирования:
- ✅ Запустите paper trading минимум на 1000 раундов (1-2 недели)
- ✅ Убедитесь что винрейт стабильно > 52%
- ✅ Проверьте максимальную просадку (< 20%)
- ❌ НЕ ЗАПУСКАЙТЕ real trading без paper trading!

## 🛠️ Troubleshooting

### Ошибка: "META недоступна"


### Низкая accuracy (<52%)

Возможные причины:
1. Недостаточно обучающих данных для фазы
2. Слишком большая uncertainty в генерации
3. Неправильные параметры обучения CEM

Решение:
- Увеличьте количество примеров на фазу
- Проверьте что фазы сбалансированы
- Настройте параметры CEM (popsize, maxiter)

### Слишком высокая accuracy (>65%)

Возможные причины:
1. Переобучение
2. Слишком простые данные
3. Утечка информации (look-ahead bias)

Решение:
- Проверьте что test данные не использовались в обучении
- Увеличьте noise и uncertainty в генерации
- Добавьте больше dropout

### Медленное обучение

CMA-ES требует времени:
- Quick test (10k): ~2-3 минуты
- Full test (360k): ~30-60 минут

Для ускорения:
- Используйте CEM вместо CMA-ES (быстрее, но хуже качество)
- Уменьшите количество итераций
- Используйте меньше MC Dropout проходов (15 вместо 30)
