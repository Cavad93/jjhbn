# 🤖 AI Trading Assistant - Руководство

## Что это?

**AI Trading Assistant** - это интеллектуальный помощник на базе **Claude Sonnet 4.5** от Anthropic, который помогает вам понимать и анализировать работу вашего торгового бота прямо в Telegram.

### Возможности

✨ **Интерактивный чат** - задавайте вопросы о боте естественным языком
📊 **AI Status** - умный анализ состояния бота (замена /status)
🔍 **Анализ решений** - почему бот открыл/закрыл позицию
💰 **Финансовая аналитика** - детальная статистика по сделкам
🛠️ **Диагностика проблем** - выявление и рекомендации по исправлению
💾 **Prompt caching** - экономия ~90% токенов
🔄 **Session management** - включение/выключение для экономии

---

## 🚀 Быстрый старт

### 1. Настройка API ключа

Откройте `.env` файл и добавьте ваш Anthropic API ключ:

```bash
ANTHROPIC_API_KEY=sk-ant-api03-xxx...
```

**Получить API ключ:**
1. Зарегистрируйтесь: https://console.anthropic.com/
2. Перейдите в Settings → API Keys
3. Создайте новый ключ
4. Скопируйте и вставьте в `.env`

### 2. Запуск бота

Запустите бота как обычно:

```bash
python3 binance_bot_main.py --paper
```

Вы увидите в логах:
```
  AI Assistant: Enabled (Claude Sonnet 4.5)
```

### 3. Использование в Telegram

#### Шаг 1: Откройте панель управления

Отправьте команду `/ai` в Telegram:

```
/ai
```

Вы получите панель с кнопками:
- **⚡ Активировать** - включить AI ассистента
- **📊 AI Status** - получить AI-анализ бота

#### Шаг 2: Активируйте AI

Нажмите кнопку **⚡ Активировать**

AI ассистент активируется и вы сможете задавать вопросы прямо в чате!

## 📊 AI Status

**AI Status** - это улучшенная версия команды `/status`, которая использует Claude для анализа состояния бота.

### Как использовать

1. Отправьте `/ai` в Telegram
2. Нажмите кнопку **📊 AI Status**

Вы получите **краткий отчет** (10 предложений) с анализом:
- Открытые позиции: количество, качество, риски
- Капитал: изменения, тренд, проблемы
- Производительность: win rate, PnL, сравнение с целями
- Проблемы: что не так (если есть)
- Рекомендации: что можно улучшить

### Пример AI Status отчета

```

У вас 7 открытых позиций на общую сумму $1,456. Большинство в прибыли (+$67.40),

Капитал вырос на $234.56 (+2.35%) за 24 часа. Тренд позитивный, резервный фонд
составляет 12% ($1,234).

Win rate 54.2% (близко к целевому 55%). За сегодня закрыто 5 сделок, 3 успешных.
Средняя прибыль $45.20, средний убыток -$23.10. R/R ratio 1.96 ✅.

Проблем не обнаружено. Night Mode активен (снижена агрессивность до UTC 07:00).
```

## 💰 Стоимость

### Pricing

**Claude Sonnet 4.5:**
- Input: $3 / 1M tokens
- Output: $15 / 1M tokens
- Cache Read: $0.30 / 1M tokens (экономия 90%!)
- Cache Write: $3.75 / 1M tokens

### Примерные расходы

**При активном использовании:**
- 10-20 вопросов в день
- AI Status 2-3 раза в день
- **Стоимость: ~$10-20/месяц**

**При умеренном использовании:**
- 5-10 вопросов в день
- AI Status 1 раз в день
- **Стоимость: ~$5-10/месяц**

### Оптимизация расходов

✅ **Активируйте AI только когда нужно** - используйте кнопку "Деактивировать"
✅ **Prompt caching работает автоматически** - системный промпт кэшируется и экономит ~90% токенов
✅ **Session timeout 30 минут** - автоматическая деактивация при неактивности
✅ **Бюджетный лимит** - в коде установлен лимит $30/месяц (можно изменить)

## 🔧 Управление сессией

### Активация

```
/ai → нажмите "⚡ Активировать"
```

AI ассистент активируется и начинает собирать контекст о боте.

**Что происходит при активации:**
1. Создается сессия пользователя
2. Собирается текущий контекст бота (позиции, капитал, статистика)
3. Контекст кэшируется в Claude для экономии токенов
4. Вы можете задавать вопросы прямо в чате

### Деактивация

```
/ai → нажмите "💤 Деактивировать"
```

AI ассистент останавливается, сессия сохраняется (можно продолжить позже).

**Когда деактивировать:**
- После того как получили нужную информацию
- Перед сном (чтобы не расходовать токены)
- При достижении бюджетного лимита

### Статистика сессии

При активной сессии панель `/ai` показывает:
- Сообщений отправлено
- Стоимость текущей сессии
- Эффективность кэширования

## 🛡️ Безопасность

### Что AI видит

AI ассистент имеет доступ к:
- ✅ Открытым позициям
- ✅ Истории сделок
- ✅ Капиталу и балансу
- ✅ Статистике моделей
- ✅ Логам и ошибкам

AI **НЕ** имеет доступа к:
- ❌ API ключам Binance
- ❌ Личным данным
- ❌ Внешним системам
- ❌ Исполнению торговых операций

### Приватность

- Все данные передаются напрямую в Anthropic API (через HTTPS)
- Сессии хранятся локально в `data/ai_assistant_cache/`
- История диалога не покидает ваш сервер (кроме запросов к API)
- Anthropic не использует данные API для обучения моделей

## ⚙️ Конфигурация

Настройки находятся в `notifications/ai_assistant.py`:

```python
class AIAssistantConfig:
    # Модель
    MODEL_ID = "claude-sonnet-4-5-20250929"
    MODEL_TEMPERATURE = 0.7  # 0.0 = детерминированный, 1.0 = креативный
    MAX_TOKENS = 4096

    # Бюджет
    MONTHLY_BUDGET_USD = 30.0  # Максимум в месяц

    # Сессия
    SESSION_TIMEOUT_MINUTES = 30  # Таймаут неактивности
    MAX_CONTEXT_MESSAGES = 20  # Макс сообщений в истории

    # Кэш
    CONTEXT_CACHE_TTL_SECONDS = 300  # 5 минут (контекст обновляется)
```

## 🐛 Troubleshooting

### AI не отвечает

**Проверьте:**
1. `ANTHROPIC_API_KEY` в `.env` корректный
2. AI сессия активна (отправьте `/ai` и проверьте статус)
3. Логи бота: `tail -f logs/binance_bot.log`
4. Telegram command listener запущен

**Решение:**
```bash
# Проверьте API ключ
cat .env | grep ANTHROPIC_API_KEY

# Перезапустите бота
pkill -f binance_bot_main
python3 binance_bot_main.py --paper
```

---

### Ошибка "Budget exceeded"

**Причина:** Достигнут месячный лимит $30

**Решение:**
1. Подождите до следующего месяца
2. Или увеличьте лимит в `AIAssistantConfig.MONTHLY_BUDGET_USD`
3. Удалите статистику для сброса: `rm data/ai_assistant_cache/assistant_stats.json`

---

### Медленные ответы

**Причина:** Claude Sonnet 4.5 обрабатывает большой контекст

**Решение:**
- Первый запрос медленнее (3-5 сек) - кэшируется контекст
- Последующие запросы быстрее (1-2 сек) - используется кэш
- Это нормально!

---

### Cache не работает

**Проверьте логи:**
```bash
grep "cache_read_input_tokens" logs/binance_bot.log
```

Если `cache_read_input_tokens=0`, кэш не используется.

**Причины:**
- Контекст бота изменился (позиции, капитал)
- Прошло > 5 минут с последнего запроса
- Новая сессия

**Решение:** Это нормальное поведение, кэш обновляется автоматически.
