## 📋 ЧТО ТЕСТИРОВАЛОСЬ

### **Базовая модель** (`prob_up_down_at_time()` из bnbusdrt6.py):

**Компоненты:**
1. **8 нормализованных сигналов:**
   - `M_up/M_dn`: Momentum (взвешенные доходности через Rogers-Satchell волатильность)
   - `S_up/S_dn`: VWAP Slope (наклон институциональных покупок)
   - `B_up/B_dn`: Keltner Breakout (пробои волатильности)
   - `R_up/R_dn`: Bollinger Reversion (mean reversion)

2. **Взвешенная комбинация:**
   ```python
   w = [0.35, 0.20, 0.20, 0.25]  # momentum, vwap, breakout, reversion
   Z_up = w[0]*M_up*volAmp + w[1]*S_up + w[2]*B_up + w[3]*R_up
   Z_dn = w[0]*M_dn*volAmp + w[1]*S_dn + w[2]*B_dn + w[3]*R_dn
   ```

3. **Softmax с адаптивной температурой:**
   ```python
   T = adaptive_temperature(volAmp, atr_norm)
   P_up = exp(Z_up/T) / (exp(Z_up/T) + exp(Z_dn/T))
   ```

4. **Пост-обработка** (7 слоев):
   - Super Smoother / EMA
   - NN Calibrator (11 фичей)
   - Кросс-активы (BTC/ETH)
   - Elder Triple Screen
   - OU processes

## ⚠️ РИСКИ И ПРЕДОСТЕРЕЖЕНИЯ

### **1. Overfitting**
Модель может отлично работать на исторических данных, но провалиться на новых.
**Решение:** Строгая валидация на hold-out данных + paper trading.

### **2. Market regime change**
Паттерны 2024 года могут не работать в 2025.
**Решение:** Регулярное переобучение (каждые 1-2 месяца).

### **3. Латентность**
Задержка транзакций может убить edge.
**Решение:** Оптимизация gas price + early betting (за 30-60 сек до lock).

### **4. Whale manipulation**
Крупные игроки могут двигать цену в последние секунды.
**Решение:** MC Dropout для uncertainty + пропуск сомнительных раундов.

### **5. Комиссия 3%**
Высокий барьер для прибыльности - нужен winrate > 50.76%.
**Решение:** Высокий precision (ставить только при уверенности > 65%).
