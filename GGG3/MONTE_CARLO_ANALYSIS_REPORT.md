## 🔍 ДЕТАЛЬНЫЙ АНАЛИЗ

### Параметры стратегии:
```
Начальный капитал: $1,000
R/R ratio: 2.5 / 1.5 = 1.667
Kelly sizing: Quarter Kelly (0.25)
Макс. позиций: 10
Размер позиции: $15 - $200
Leverage: 1x (без плеча)
Trailing Stop: 2% активация, 1% дистанция
Max hold time: 72 часа
Ребалансировка: каждые 4 часа
```

### Факторы успеха:

1. **Kelly Sizing (Quarter Kelly)**
   - Оптимизирует размер позиций под вероятность выигрыша
   - Fractional Kelly (0.25) снижает волатильность
   - Ограничения 0.5% - 2.5% защищают от чрезмерного риска

2. **Положительный R/R Ratio (1.667)**
   - TP = 2.5 ATR, SL = 1.5 ATR
   - Прибыльные сделки приносят на 67% больше убыточных
   - Компенсирует даже WR < 50%

3. **Trailing Stop**
   - Увеличивает прибыль на выигрышных сделках
   - В оптимистичном сценарии: +30% сделок с бонусом
   - Средний бонус: +0.3-0.5R

4. **Диверсификация (до 10 позиций)**
   - Снижает влияние одной неудачной сделки
   - Сглаживает волатильность портфеля

## 📎 ПРИЛОЖЕНИЯ

### A. Методология симуляции

- 10,000 независимых траекторий на сценарий
- Случайное распределение выигрышей/проигрышей
- Пуассоновское распределение количества сделок
- Учет комиссий, слипейджа, trailing stops

**Допущения:**
- Стационарность WR (не меняется со временем)
- Независимость сделок
- Нормальное рыночное поведение (без экстремальных событий)
- Корректная работа биржи и моделей

### B. Формулы

**Kelly Criterion:**
```
f = (p × b - q) / b
где:
  p = вероятность выигрыша
  q = 1 - p
  b = R/R ratio

Fractional Kelly = f × 0.25
```

**Sharpe Ratio:**
```
SR = (μ - rf) / σ × √365
где:
  μ = средняя дневная доходность
  rf = безрисковая ставка (≈0)
  σ = ст. откл. дневной доходности
```

**R/R Ratio:**
```
R/R = TP_ATR_MULTIPLIER / SL_ATR_MULTIPLIER
    = 2.5 / 1.5 = 1.667
```
