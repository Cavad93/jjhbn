# AI Assistant Tools - Инструменты для экономии токенов

## 🎯 Что это?

AI ассистент теперь может **запрашивать данные по требованию** вместо постоянной отправки всего контекста.

**Раньше (без инструментов):**
```
Каждое сообщение = 5000+ токенов контекста (все позиции, история, статистика)
10 сообщений = 50,000+ токенов = дорого 💸
```

**Теперь (с инструментами):**
```
Сообщение 1 = 1000 токенов (системный промпт)
AI вызывает инструмент: get_open_positions → 200 токенов
AI отвечает: 500 токенов
ИТОГО: 1,700 токенов вместо 5,000+ 🎉
```

## 📊 Доступные инструменты

### 1. **get_open_positions**
Получить список всех открытых позиций

```json
{
  "include_details": false  // true для полных данных
}
```

**Возвращает:**
- Symbol, direction, entry_price, current_price
- Current PnL %
- TP/SL levels
- Entry time
- ATR value
- (опционально) p_up, EV, expert predictions

### 2. **get_position_details**
Детальная информация о конкретной позиции

```json
{
  "symbol": "BTCUSDT"
}
```

**Возвращает:**
- Все данные из entry_snapshot
- Predictions от экспертов (p_up, EV)
- Рыночные условия при входе
- Индикаторы (68D features вектор доступен но не передаётся)
- Причина открытия/закрытия

### 3. **get_closed_positions**
История закрытых позиций

```json
{
  "limit": 10,              // Последние N позиций
  "result_filter": "ALL"    // "WIN", "LOSS", или "ALL"
}
```

**Возвращает:**
- Entry/close price and time
- PnL и PnL %
- Причина закрытия (TP/SL/manual)
- Результат (WIN/LOSS)

### 4. **search_positions**
Поиск позиций по критериям

```json
{
  "symbol_pattern": "BTC*",    // Паттерн (например, "ETH*")
  "status": "closed",          // "open", "closed", "all"
  "date_from": "2025-11-15",   // ISO format
  "date_to": "2025-11-17"      // ISO format
}
```

**Возвращает:**
- Все подходящие позиции с основной информацией

### 5. **get_bot_status**
Общий статус бота

```json
{}  // Без параметров
```

**Возвращает:**
- Balance, equity
- Количество открытых/закрытых позиций
- Winrate, wins, losses
- Paper mode status

## 🎭 Примеры использования

### Пример 1: Узнать о конкретной позиции

**Вопрос пользователя:**
```
Почему бот открыл позицию по BTCUSDT?
```

**Что делает AI:**
1. Вызывает `get_position_details(symbol="BTCUSDT")`
2. Получает entry_snapshot с predictions
3. Анализирует p_up, EV, expert predictions
4. Отвечает: "Бот открыл LONG по BTCUSDT потому что..."

**Экономия токенов:**
- Без инструментов: ~5000 токенов (весь контекст)
- С инструментами: ~1500 токенов (только BTCUSDT данные)
- **Экономия: 70%** 💰

### Пример 2: Анализ винрейта

**Вопрос:**
```
Какой винрейт на последних 20 сделках?
```

**AI делает:**
1. Вызывает `get_closed_positions(limit=20, result_filter="ALL")`
2. Считает wins/losses
3. Отвечает с конкретными цифрами

### Пример 3: Поиск убыточных ETH трейдов

**Вопрос:**
```
Покажи все убыточные сделки по Ethereum за последнюю неделю
```

**AI делает:**
1. Вызывает `search_positions(symbol_pattern="ETH*", status="closed", date_from="2025-11-10")`
2. Фильтрует результаты с pnl < 0
3. Анализирует паттерны ошибок

## 🚀 Активация

Инструменты **автоматически включены** если:
1. ✅ `bot_instance` передан в `AITradingAssistant`
2. ✅ Anthropic API key настроен

**Проверка в логах:**
```
[AITradingAssistant] Tools enabled
```

Если видите:
```
[AITradingAssistant] No bot_instance - tools disabled
```

Значит bot_instance не передан → инструменты не работают.

## 🔧 Разработка новых инструментов

Добавить новый инструмент просто:

### 1. Определить в `ai_assistant_tools.py`:

```python
{
    "name": "get_expert_stats",
    "description": "Статистика точности ML моделей",
    "input_schema": {
        "type": "object",
        "properties": {
            "expert_name": {
                "type": "string",
                "description": "Название эксперта (xgb, rf, nn, meta)"
            }
        }
    }
}
```

### 2. Реализовать в `AIAssistantTools`:

```python
def _get_expert_stats(self, expert_name: str) -> str:
    # Получить статистику из бота
    stats = self.bot.get_expert_statistics(expert_name)
    return json.dumps(stats, indent=2)
```

### 3. Добавить в `execute_tool`:

```python
elif tool_name == "get_expert_stats":
    return self._get_expert_stats(**tool_input)
```

Готово! AI автоматически начнёт использовать новый инструмент.

## ❓ FAQ

**Q: AI не использует инструменты, почему?**
A: Проверьте логи. Если `tools disabled` → bot_instance не передан. Проверьте инициализацию AITradingAssistant.

**Q: Можно ли отключить инструменты?**
A: Да, передайте `bot_instance=None` в AITradingAssistant.

**Q: Сколько раундов tool calls максимум?**
A: 5 раундов (настраивается в `_process_response`).

**Q: Инструменты работают в paper_bot?**
A: Нет, только в binance_bot_main.py. Для paper_bot нужно добавить инициализацию AITradingAssistant.
