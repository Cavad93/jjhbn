# 🧹 Удаление старого бота PostgreSQL 12 и установка нового

## 📋 Пошаговая инструкция для Windows Server 2012 R2

---

## ⚠️ ВАЖНО: Перед началом

1. **Закройте все программы**, которые могут использовать Python или старый бот
2. **Сделайте резервную копию** важных данных (если есть)
3. **Откройте Command Prompt от имени администратора**:
   - Нажмите `Win + X`
   - Выберите "Command Prompt (Admin)" или "Командная строка (Администратор)"

---

## 🔴 ШАГ 1: Остановить старый бот (если запущен)

```batch
REM Найти процессы Python
tasklist | findstr python

REM Если найдены процессы, остановить их
taskkill /F /IM python.exe
taskkill /F /IM pythonw.exe
```

**Результат:** Все процессы Python остановлены

---

## 🔴 ШАГ 2: Перейти в папку старого бота

```batch
REM Замените путь на свой!
cd C:\path\to\old_bot

REM Проверьте текущую папку
cd
```

**Пример:**
```batch
cd C:\Users\Admin\Desktop\old_pancakeswap_bot
```

---

## 🔴 ШАГ 3: Деактивировать виртуальное окружение (если активно)

```batch
REM Если видите (venv) или другое название окружения в начале строки, деактивируйте:
deactivate
```

---

## 🔴 ШАГ 4: Удалить старое виртуальное окружение

```batch
REM Удалить папку venv (если существует)
if exist venv rmdir /S /Q venv

REM Удалить другие возможные названия
if exist .venv rmdir /S /Q .venv
if exist env rmdir /S /Q env
```

**Результат:** Старое виртуальное окружение удалено

---

## 🔴 ШАГ 5: Очистить кэш pip

```batch
REM Очистить кэш pip (освобождает место)
python -m pip cache purge
```

**Результат:** Кэш очищен

---

## 🔴 ШАГ 6: Удалить глобальные зависимости PostgreSQL (опционально)

⚠️ **ВНИМАНИЕ:** Это удалит библиотеки для ВСЕХ Python проектов на компьютере!

```batch
REM Удалить PostgreSQL библиотеки глобально
python -m pip uninstall -y psycopg2-binary psycopg2 asyncpg

REM Удалить другие старые библиотеки
python -m pip uninstall -y web3 sqlalchemy pandas numpy
```

**Рекомендация:** Пропустите этот шаг, если используете виртуальные окружения (рекомендуется)

## 🐛 Решение проблем

### Проблема 1: "python" не распознается

**Решение:**
```batch
REM Добавьте Python в PATH или используйте полный путь
C:\Python38\python.exe --version
```

### Проблема 2: Ошибка при установке пакетов

**Решение:**
```batch
REM Обновите pip
python -m pip install --upgrade pip

REM Повторите установку
install.bat
```

### Проблема 3: Не могу удалить папку venv

**Решение:**
```batch
REM Перезагрузите компьютер и повторите
shutdown /r /t 0

REM Или используйте PowerShell от администратора
powershell -Command "Remove-Item -Recurse -Force venv"
```

### Проблема 4: "Отказано в доступе"

**Решение:**
1. Закройте все программы, использующие Python
2. Откройте Command Prompt от имени администратора
3. Повторите команды
