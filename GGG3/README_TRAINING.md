# Обучение бота на исторических данных

## Описание

Этот набор скриптов позволяет полностью обучить торгового бота на исторических данных с 2022 года по настоящее время.

## Компоненты системы

### 1. Сбор данных

**collect_historical_data.py** - Собирает реальные исторические данные с BSC blockchain:
- Подключается к контракту PancakeSwap Prediction через Web3
- Загружает данные раундов с января 2022 года
- Получает исторические цены BNB с Binance API
- Вычисляет технические индикаторы (momentum, volatility, RSI, etc.)
- Сохраняет данные в JSON формате

### 2. Генерация синтетических данных

**generate_realistic_data.py** - Генерирует реалистичные синтетические данные:
- Симулирует движение цены BNB с реалистичными трендами
- Генерирует технические индикаторы
- Создает данные для всех 6 рыночных фаз (по волатильности)
- Используется когда нет доступа к BSC RPC

### 3. Полное обучение бота

**train_bot_full.py** - Главный скрипт обучения:
- Собирает реальные данные с BSC (или использует синтетические)
- Обучает все 4 эксперта: XGBoost, RandomForest, ARF, NN
- Обучает META Neural на предсказаниях экспертов
- Сохраняет обученные модели

## Установка зависимостей

```bash
pip3 install --break-system-packages pandas xgboost scikit-learn river web3 requests python-dotenv numpy scipy
```

## Использование

### Вариант 1: Обучение на реальных данных (рекомендуется)

Если у вас есть доступ к BSC RPC:

```bash
python3 train_bot_full.py
```

Скрипт автоматически:
1. Подключится к BSC RPC
2. Соберет исторические данные с 2022 года
3. Обучит всех экспертов
4. Обучит META Neural
5. Сохранит модели

**Ожидаемое время**: 30-60 минут (зависит от скорости RPC)
**Требуемые данные**: ~50,000+ раундов для оптимального обучения META

### Вариант 2: Обучение на синтетических данных

Если нет доступа к BSC RPC:

```bash
# Сначала сгенерируйте данные
python3 generate_realistic_data.py

# Затем обучите бот
python3 train_bot_full.py --use-synthetic
```

**Ожидаемое время**: 15-30 минут
**Данные**: 60,000 синтетических раундов

### Вариант 3: Сбор только данных

Если хотите только собрать данные:

```bash
# Сбор 5000 раундов
python3 collect_historical_data.py
```

Данные сохранятся в `pancakeswap_historical_5k.json`

## Эксперты бота

### 1. XGBoost Expert
- Gradient boosting алгоритм
- Лучше всего работает на средних фазах волатильности
- Имеет ADWIN drift detection
- Калибровка: Platt scaling

### 2. RandomForest Expert
- Ensemble из деревьев решений
- Стабилен на разных рыночных условиях
- Калибровка: Sigmoid calibration
- Батчевое дообучение

### 3. ARF (Adaptive Random Forest) Expert
- Онлайн-обучение (River library)
- Адаптируется к изменениям в реальном времени
- Не требует переобучения
- Калибровка: Platt scaling

### 4. NN (Neural Network) Expert
- Компактная MLP: [10 → 32 → 1]
- Быстрое обучение
- Калибровка: Temperature scaling
- Хорошо работает на сложных паттернах

### META Neural
- Архитектура: Attention module + Main network [36 → 64 → 32 → 16 → 1]
- Всего параметров: 5,189
- Оптимизатор: CMA-ES/CEM (эволюционный алгоритм)
- Принимает на вход предсказания всех экспертов + контекст
- Выдает финальную вероятность UP

## Проблемы и решения

### Проблема: "Не удалось подключиться к BSC RPC"

**Решения:**
1. Используйте `--use-synthetic` флаг
2. Проверьте интернет-подключение
3. Попробуйте другие RPC endpoints (скрипт пробует 5 разных)
4. Используйте VPN если RPC блокируется

### Проблема: "META не улучшает результаты"

**Причины:**
1. Недостаточно данных (< 50,000 примеров)
2. Данные низкого качества
3. Слишком простые паттерны в данных

**Решения:**
1. Соберите больше данных (минимум 50,000 раундов)
2. Используйте реальные данные вместо синтетических
3. Проверьте баланс классов (должно быть ~50/50 UP/DOWN)

### Проблема: "ImportError: No module named..."

**Решение:**
```bash
pip3 install --break-system-packages pandas xgboost scikit-learn river web3 requests python-dotenv numpy scipy
```

## Минимальные требования к данным

Для оптимальной работы META Neural:

| Параметр | Значение | Примечание |
|----------|----------|------------|
| Минимум примеров | 50,000 | 10x от количества параметров |
| Оптимум примеров | 100,000+ | 20x от количества параметров |
| Баланс классов | 45-55% | Близко к 50/50 UP/DOWN |
| Период данных | 2+ года | Разные рыночные условия |
| Все фазы | ✓ | Данные должны покрывать все 6 фаз |

## Следующие шаги после обучения

1. **Проверка моделей**: Убедитесь что META показывает улучшение > 0%
2. **Backtesting**: Протестируйте на новых данных (не из обучающей выборки)
3. **Paper trading**: Запустите бота в режиме paper trading
4. **Мониторинг**: Следите за метриками в реальном времени
5. **Дообучение**: Периодически дообучайте на новых данных

## Сохранение и загрузка моделей

Модели сохраняются в директории `trained_models/`:

```
trained_models/
├── gb_model.json              # XGBoost модель
├── gb_scaler.pkl             # XGBoost скейлер
├── rf_calibrated.pkl         # RandomForest модель
├── arf_model.pkl             # ARF модель
├── nn_model.pkl              # NN модель
├── nn_scaler.pkl             # NN скейлер
└── meta_neural_state.json    # META Neural состояние
```

Для использования обученных моделей в боте - скопируйте файлы в рабочую директорию бота.
