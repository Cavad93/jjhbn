# 🛑 Команда /closeall - Экстренное закрытие всех позиций

## Что это?

**`/closeall`** - команда для принудительного закрытия **ВСЕХ** открытых позиций через Telegram.

Используется в экстренных ситуациях:
- Паника на рынке
- Необходимость срочно вывести средства
- Сильные убытки по нескольким позициям
- Проблемы с ботом

---

## 🚀 Как использовать

### Шаг 1: Отправьте команду

```
/closeall
```

### Шаг 2: Проверьте информацию

Бот покажет панель подтверждения:

```
⚠️ ЗАКРЫТИЕ ВСЕХ ПОЗИЦИЙ

Вы уверены что хотите закрыть ВСЕ открытые позиции?

📊 Будет закрыто: 7 позиций
💰 Общий объём: $1,456.00

⚠️ Это действие нельзя отменить!

[✅ Да, закрыть ВСЕ]  [❌ Отмена]
```

### Шаг 3: Подтвердите или отмените

**Для закрытия:**
- Нажмите кнопку **✅ Да, закрыть ВСЕ**

**Для отмены:**
- Нажмите кнопку **❌ Отмена**

---

## 📊 Что происходит при закрытии

1. **Бот получает все открытые позиции**
2. **Для каждой позиции:**
   - Получает текущую рыночную цену
   - Вычисляет PnL (прибыль/убыток)
   - Закрывает позицию через PositionManager
   - Отправляет уведомление о закрытии
3. **Формирует финальный отчет:**

```
✅ ВСЕ ПОЗИЦИИ ЗАКРЫТЫ

📊 Закрыто: 7 позиций
💰 Общий PnL: +$123.45

Детали:
  • BTCUSDT: +$45.20
  • ETHUSDT: +$23.10
  • SOLUSDT: -$12.50
  • BNBUSDT: +$34.80
  • ADAUSDT: +$18.90
  ... и ещё 2
```

## ⚠️ Важные замечания

### Безопасность
- ✅ **Требуется подтверждение** - случайное нажатие не закроет позиции
- ✅ **Показывает количество и объём** - вы видите что именно закрываете
- ✅ **Детальный отчет** - PnL по каждой позиции после закрытия
- ✅ **Логирование** - все действия записываются в лог

### Технические детали
- Позиции закрываются **по рыночной цене** (market order)
- Закрытие происходит **последовательно** (не параллельно)
- Если одна позиция не закроется - остальные продолжат закрываться
- После закрытия **баланс обновляется автоматически**

### Когда НЕ использовать
- ❌ Если у вас **все позиции в плюсе** - лучше дождаться TP
- ❌ Если паника **временная** - дождитесь стабилизации
- ❌ Если **одна** позиция в убытке - закройте только её (через /status)

## 🔧 Troubleshooting

### Команда не работает

**Проблема:** Ничего не происходит после `/closeall`

**Решение:**
1. Проверьте что бот запущен
2. Проверьте что Telegram command listener активен (в логах)
3. Перезапустите бота

---

### Не все позиции закрылись

**Проблема:** Бот показал "Не удалось закрыть: 2 позиций"

**Причины:**
- Проблемы с Binance API
- Недостаточная ликвидность
- Позиция уже закрыта

**Решение:**
- Проверьте логи: `tail -f logs/binance_bot.log`
- Проверьте позиции через `/status`
- Попробуйте `/closeall` ещё раз

---

### Закрыл по ошибке

**Проблема:** Случайно закрыл все позиции

**К сожалению:** Отменить нельзя, позиции уже закрыты по рыночной цене

**Что делать:**
1. Проверьте баланс через `/status`
2. Если хотите вернуться в рынок - дождитесь новых сигналов
3. Бот автоматически откроет новые позиции по своей стратегии
