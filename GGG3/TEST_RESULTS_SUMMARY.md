## ✅ Подтверждённые формулы

### Открытие LONG позиции:
```
exec_price = market_price × (1 + slippage)         // +0.05%
cost = exec_price × amount
commission = cost × 0.001                           // 0.1%
balance_new = balance_old - (cost + commission)     ✅
```

**Пример:**
```
Market price: $50,000
Slippage:     $50,000 × 1.0005 = $50,025
Amount:       0.01 BTC
Cost:         $50,025 × 0.01 = $500.25
Commission:   $500.25 × 0.001 = $0.50
Total:        $500.75
Balance:      $1,000 - $500.75 = $499.25 ✅
```

---

### Закрытие LONG позиции:
```
exec_price = market_price × (1 - slippage)         // -0.05%
revenue = exec_price × amount
commission = revenue × 0.001                        // 0.1%
received = revenue - commission
balance_new = balance_old + received                ✅
```

**Пример (прибыль):**
```
Market price: $51,000
Slippage:     $51,000 × 0.9995 = $50,974.50
Amount:       0.01 BTC
Revenue:      $50,974.50 × 0.01 = $509.75
Commission:   $509.75 × 0.001 = $0.51
Received:     $509.75 - $0.51 = $509.24
Balance:      $499.25 + $509.24 = $1,008.49 ✅
```

---

### Итоговый баланс:
```
Final Balance = Initial Balance + Net PnL           ✅
где Net PnL = Gross PnL - All Commissions
```

**Проверено на 10 сделках:**
