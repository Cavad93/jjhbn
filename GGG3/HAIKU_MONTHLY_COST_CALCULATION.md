- Нет кэша

```
Монет в TOP-20: 20
Batch size: 5 монет/запрос

Стоимость за ребалансировку:
4 запроса × $0.0135 = $0.054

6 × $0.054 = $0.324/день

Стоимость в месяц:
$0.324 × 30 = $9.72/месяц
```

**Без оптимизаций: ~$9.72/месяц**

### Сценарий 2: С кэшированием результатов (текущий)

**Логика кэширования (`haiku_analyzer.py:306-342`):**
- Стабильные монеты (BTC, ETH, BNB): кэш 12 часов
- Волатильные монеты (остальные 17): кэш 4 часа

**Как работает кэш:**
```python
# При каждой ребалансировке:
1. Проверяется кэш для каждой монеты
2. Если кэш свежий → берётся из кэша (API НЕ вызывается)
3. Если кэш устарел → делается API запрос
```

**Расчёт количества API запросов за день:**

| Время | Волатильные (17) | Стабильные (3) | Всего монет | API запросов |
|-------|------------------|----------------|-------------|--------------|
| 00:00 | Анализируем (кэш пустой) | Анализируем | 20 | 4 |
| 04:00 | Анализируем (кэш 4ч истёк) | Кэш свежий (4ч/12ч) | 17 | 4 |
| 08:00 | Анализируем | Кэш свежий (8ч/12ч) | 17 | 4 |
| 12:00 | Анализируем | Анализируем (12ч истёк) | 20 | 4 |
| 16:00 | Анализируем | Кэш свежий (4ч/12ч) | 17 | 4 |
| 20:00 | Анализируем | Кэш свежий (8ч/12ч) | 17 | 4 |

**Итого API запросов за день:** 24 запроса

**Экономия от кэша стабильных монет:**
```
Без кэша: 6 × 4 = 24 запроса
С кэшем: 24 запроса (разница минимальная из-за округления batch)
```

**Причина:** 17 монет требуют 4 запроса [5,5,5,2], как и 20 монет [5,5,5,5].

**Стоимость:**
```
24 запроса × $0.0135 = $0.324/день
$0.324 × 30 = $9.72/месяц
```

**С кэшированием результатов: ~$9.72/месяц** (экономия ~0%)

### Сценарий 3: С Prompt Caching (Anthropic API)

**Prompt caching (`haiku_analyzer.py:490-494`):**
```python
system=[
    {
        "type": "text",
        "text": self.SYSTEM_PROMPT,
        "cache_control": {"type": "ephemeral"}  # Кэшируем системный промпт
    }
]
```

**Как работает Prompt Caching:**
- Системный промпт (~500 tokens) кэшируется на 5 минут
- При повторном использовании: input tokens стоят $0.1/M вместо $1/M (90% экономия)
- Наши 4 запроса идут подряд в рамках одной ребалансировки (~1-2 минуты)

**Разбивка стоимости запроса:**

**Первый запрос в ребалансировке:**
```
System prompt: 500 tokens × $1/M = $0.0005
User prompt: 3000 tokens × $1/M = $0.003
Output: 2000 tokens × $5/M = $0.01
─────────────────────────────────────────
Итого: $0.0135
```

**Последующие 3 запроса (с кэшированным промптом):**
```
System prompt (cached): 500 tokens × $0.1/M = $0.00005
User prompt: 3000 tokens × $1/M = $0.003
Output: 2000 tokens × $5/M = $0.01
─────────────────────────────────────────
Итого: $0.01305
```

**Стоимость за одну ребалансировку (4 запроса):**
```
1 запрос: $0.0135
3 запроса: 3 × $0.01305 = $0.03915
─────────────────────────────────────────
Итого: $0.05265
```

**За день:**
```
6 ребалансировок × $0.05265 = $0.3159/день
```

**За месяц:**
```
$0.3159 × 30 = $9.48/месяц
```

**С Prompt Caching: ~$9.48/месяц** (экономия ~2.5%)

### Сценарий 4: С учётом пропуска слабых сигналов

**Логика (`haiku_analyzer.py:359-372`):**
```python
def _should_skip_analysis(self, opportunity: dict) -> bool:
    # Пропускаем очень слабые сигналы
    if opportunity.get('p_up', 0.5) < 0.35:
        return True  # Заведомо плохая сделка
```

**Эффект:**
- Монеты с p_up < 0.35 НЕ анализируются (используется fallback)
- В среднем 10-20% монет из TOP-20 могут иметь p_up < 0.35

**Допустим, 15% монет пропускаются:**
```
Монет для анализа: 20 × 0.85 = 17 монет
API запросов: 17 / 5 = 4 запроса (округление вверх)
```

**Стоимость:** ~$9.48/месяц (без изменений из-за округления)

## 💡 Как снизить стоимость?

### Опция 1: Увеличить интервал ребалансировки

**С 4 часов до 6 часов:**
```
Ребалансировок в день: 24/6 = 4 раза
Стоимость: $9.48 × (4/6) = $6.32/месяц
Экономия: -33%
```

**Риск:** Упущенные возможности, менее актуальный портфель

### Опция 2: Уменьшить TOP-20 до TOP-15

```
Монет: 15
API запросов: 15/5 = 3 за ребалансировку
Стоимость: $9.48 × (3/4) = $7.11/месяц
Экономия: -25%
```

**Риск:** Меньше диверсификация

### Опция 3: Анализировать только TOP-10

```
Монет: 10
API запросов: 10/5 = 2 за ребалансировку
Стоимость: $9.48 × (2/4) = $4.74/месяц
Экономия: -50%
```

**Риск:** Haiku не влияет на выбор TOP-10, только валидирует их

### Опция 4: Динамический анализ (рекомендуется)

```python
# Анализировать только если:
# 1. Монета новая в TOP-20 (не была в прошлом TOP-20)
# 2. Изменение цены > 10% за 4 часа (сильное движение)
# 3. Spike объёма > 2x средний

Ожидаемое снижение запросов: -30-40%
Стоимость: $9.48 × 0.65 = $6.16/месяц
```
